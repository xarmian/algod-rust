## Gaps summary

- **No global-vs-local `ResourceTracker` model** (`TestAppAccounts`, `TestGlobalVsLocalResources`): algod-rust's `UnnamedResourcesAccessed` is a flat set of accessed resources; it has no per-txn-vs-group-shared assignment structure, no `Max*` capacity fields, and no cross-product (`MaxCrossProductReferences`) tracking at all. This cascades into every `TestUnnamedResources*` variant that reports resource *limits* rather than just *access*: `TestUnnamedResourcesCreatedAppsAndAssets`, `TestUnnamedResourcesCrossProductLimits`, `TestUnnamedResourcesLimits` (partial). Tracked by issue #970.
- **No empty-box-ref / IO-budget suggestion feature**: `TestUnnamedResourcesBoxIOBudget`, `TestUnnamedResourcesBigProgramReadBudget`, `TestUnnamedResourcesLargeUnnamedAppReadBudget`, `TestUnnamedResourcesLargeProgramCreateWriteBudget` all depend on a `NumEmptyBoxRefs`-style suggestion mechanism that does not exist on `UnnamedResourcesAccessed`. Tracked by issue #970.
- **No nested inner-txn `FailedAt` path** (the `cursorEvalTracer`/`TxnPath` gap): `group_result.failed_at` in `crates/core/algo-ledger/src/simulation/mod.rs` is always set to a single top-level transaction index (`Some(vec![i])`), never a path descending into inner transactions (e.g. go's `{2, 0, 0}`). This affects `TestCursorEvalTracer` (not-implemented) and weakens the otherwise-reasonable matches for `TestAppCallInnerTxnApplyDataOnErr`, `TestNonAppCallInnerTxnApplyDataOnErr`, and `TestInnerTxnNonAppCallErr` (all partial). Tracked by issue #972.
- ~~**No post-quantum (Falcon) signature verification in simulate**: `TestPlaceholderPQSignatures` is not-implemented — the `PQSig` wire type exists but its verification/FixSigners integration is explicitly deferred per a code comment in `consensus.rs`.~~ **Fixed** in issue #835 (PR #844).
- **PC/stack-trace combination gaps**: the PC-trace and stack-trace mechanisms are each implemented and unit-tested individually, but several go tests combine them with specific scenarios (deep recursive app-call depth, rejecting LogicSig/app, `frame_bury`/`frame_dig`/`dupn`/`popn` opcodes) that have no matching integration test — `TestMaxDepthAppWithPCTrace`, `TestLogicSigPCandStackExposure`, `TestInvalidLogicSigPCandStack`, `TestInvalidApp`, `TestFrameBuryDigStackTrace` (all partial). Tracked by issue #974.
- **Initial-states coverage is uneven**: global initial-state capture has a full integration test, but local-state and box-state initial-state capture are only unit-tested at the `InitialStatesAccumulator` level (no end-to-end AVM-driven test) — `TestLocalInitialStates`, `TestAppInitialBoxStates`, `TestAppInitialBoxStatesAboutBoxPut`, `TestInitialStatesGetEx`, `TestForeignAppBoxStateChangeTrace` (all partial). Tracked by issue #974.
- **Signature-mode edge cases untested at the simulation level**: `TestWrongAuthorizerTxn`, `TestDefaultSignatureCheck`, `TestOptionalSignatures`, `TestOptionalSignaturesIncorrect`, `TestOptionalSignaturesProgramlessLogicSigContent`, `TestPartialMissingSignatures` all rely on generic `algo-validate` signature-check behavior that is exercised elsewhere but never through a simulate-specific test. Tracked by issue #974.
- **Miscellaneous missing-test items** where the underlying feature is implemented but unexercised by a test: `TestStateProofTxn` (StateProof rejection message), `TestSimpleGroupTxn` (group-membership check), `TestStartRound` (round-parameter selection), `TestInvalidTxGroup` (incentive-pool rejection classification), `TestGlobalStateTypeChangeErr` (global-state type-mismatch trace), `TestBalanceChangesWithApp` (mid-group balance visibility), `TestUnnamedResourcesAccountLocalWrite` (unnamed local-write tracking), `TestRekey` (simulate-specific rekey flow), `TestTxnNeedsSyntheticSignatureLogicSigContent` (the `txn_has_no_signature` helper). Tracked by issue #974.
- **Out of scope**: `TestNonOverridenDataLedgerMethodsUseRoundParameter` is a Go-specific reflection audit of `data.Ledger`'s method surface against `eval.LedgerForEvaluator`; algod-rust's `LedgerStore` trait has a structurally different architecture with no equivalent surface to audit.
